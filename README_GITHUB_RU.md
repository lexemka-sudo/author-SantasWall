# S. 壁 — загрузка проекта в GitHub

В репозитории должны лежать файлы проекта прямо в корне:

- `app.py`
- `requirements.txt`
- `render.yaml`
- папка `templates/`
- `README_RU.md`
- `.gitignore`

## Как загрузить через телефон
1. Скачайте ZIP и распакуйте его на телефоне.
2. Откройте GitHub и создайте новый репозиторий (например, `s-wall-author-platform`).
3. Откройте репозиторий → **Add file** → **Upload files**.
4. Выберите распакованные файлы и папку `templates` (не загружайте сам ZIP вместо файлов).
5. Нажмите **Commit changes**.

После загрузки подключите этот репозиторий к хостингу, который поддерживает Python/Flask. GitHub сам по себе не запускает Flask-приложение и не создаёт публичный работающий сайт.

## Важно
- Не добавляйте пароли и секретные ключи в репозиторий.
- Пароль владельца не хранится в HTML; проверка прав выполняется сервером.
- Для сохранения аккаунтов, произведений и глав хостинг должен предоставлять постоянное хранилище для SQLite.
