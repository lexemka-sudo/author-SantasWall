# S. 壁 — готовый серверный проект

## Что уже реализовано
- Регистрация читательских аккаунтов и вход.
- Владелец с логином `SantasWall2006`; пароль задан при подготовке и хранится только как серверный PBKDF2-хеш.
- Серверная проверка прав: только владелец может создавать, менять и удалять произведения и главы.
- Каталог, карточки произведений, чтение глав и комментарии.
- SQLite-база данных и шаблон развертывания Render с постоянным диском.

## Как получить общую ссылку
Это серверное приложение, а не HTML-файл для открытия двойным нажатием. Для реальной регистрации нужно развернуть его в интернете:
1. Создай аккаунт на Render.
2. Загрузи этот проект в GitHub и подключи репозиторий как Web Service в Render.
3. Render прочитает `render.yaml`, установит зависимости и запустит сайт.
4. После публикации открой выданную ссылку — это и будет сайт для тебя и читателей.

Проверь актуальные тарифы и условия Render перед подтверждением. Не публикуй пароль владельца.

## Локальная проверка
Python 3.10+:
```bash
pip install -r requirements.txt
python app.py
```
Открой http://127.0.0.1:5000

База создаётся автоматически. На хостинге обязательно оставь постоянный диск, иначе данные могут потеряться при пересоздании приложения.
